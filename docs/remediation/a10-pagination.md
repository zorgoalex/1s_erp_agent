# A10 — пагинация continuation (частичное исправление)

Дата: 24.09.2026. Исполнитель: OpenCode, opencode-go/mimo-v2.6-pro.

После получения nextLink клиент остаётся в режиме continuation до последней страницы: отсутствие ссылки завершает чтение даже при полном пакете. Возврата к устаревшему $skip нет. Ссылки разрешаются относительно текущего запроса, включая query-only; проверяются origin и граница пути OData.

Оркестратор проверил два изменённых файла и red/green-логи. Перед переносом из agents/worktrees/a10 исходные файлы основного каталога побайтово совпали с baseline.

Регрессия без исправления возвращала A,B,C,D,C,D,C,D вместо A,B,C,D. Финальный Windows Release-прогон изолированной копии: 24/24 unit, в том числе16 OData-тестов. Проверены полная и пустая терминальные страницы, skip без nextLink, v3 d.__next, относительные/query-only/абсолютные ссылки, внешний origin и выход за границы сервиса. [Логи и TRX](../../local-data/remediation-2026-09-24/a10/).

Объединённая проверка основного дерева после полной пересборки: 52/52; после замечаний A02 — 57/57 (30 unit + 27 integration), Release build без ошибок/предупреждений.
